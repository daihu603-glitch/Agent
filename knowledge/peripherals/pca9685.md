# PCA9685 — 16 路 PWM 控制器

## 基本参数
- 接口: I2C (最高 1MHz)
- 默认地址: 0x40 (A0-A5 全接地)
- 地址范围: 0x40 ~ 0x7F (6 位地址引脚)
- PWM 分辨率: 12bit (0-4095)
- PWM 频率: 24Hz ~ 1526Hz
- 输出: 16 路 (LED0-LED15), 每路可独立设置开/关计数
- 供电: VDD=2.3-5.5V, V+=舵机电源(独立)
- OE 引脚: 低电平使能输出，高电平全部关闭

## 关键寄存器
| 地址 | 名称 | 功能 |
|------|------|------|
| 0x00 | MODE1 | 模式寄存器1 (SLEEP bit4, ALLCALL bit0) |
| 0x01 | MODE2 | 模式寄存器2 (OUTDRV bit2, INVRT bit4) |
| 0x02-0x05 | SUBADR1-3 | 子地址 |
| 0x06 | ALLCALLADR | 全呼叫地址 |
| 0x07+4n | LEDn_ON_L | 通道n开启计数低字节 |
| 0x08+4n | LEDn_ON_H | 通道n开启计数高字节 |
| 0x09+4n | LEDn_OFF_L | 通道n关闭计数低字节 |
| 0x0A+4n | LEDn_OFF_H | 通道n关闭计数高字节 |
| 0xFA-0xFD | ALL_LED_ON/OFF | 全通道同时设置 |
| 0xFE | PRE_SCALE | 预分频 (设置PWM频率) |

## PWM 频率计算
```
prescale = round(25MHz / (4096 × freq_Hz)) - 1
```
- 50Hz (舵机): prescale = 121 (0x79)
- 60Hz: prescale = 101
- 设置频率时必须先 SLEEP → 写 PRE_SCALE → 唤醒

## 舵机控制公式 (50Hz)
- 周期 = 4096 counts = 20ms
- 0.5ms (0°) → count = 102
- 1.5ms (90°) → count = 307
- 2.5ms (180°) → count = 512
- angle → count = 102 + (angle / 180) × 410

## 初始化序列
1. 写 MODE1 = 0x10 (SLEEP=1, 进入睡眠)
2. 写 PRE_SCALE = 121 (50Hz)
3. 写 MODE1 = 0x00 (唤醒, ALLCALL=0)
4. 等待 5ms (振荡器稳定)
5. 写 MODE1 = 0xA0 (RESTART=1, AUTO_INC=1)
6. 写 MODE2 = 0x04 (推挽输出)

## 当前项目接线
- 第一块: I2C1 (PB6=SCL, PB7=SDA), 地址 0x40, CH0-8 → 舵机 0-8
- 第二块: I2C2 (PB10=SCL, PB11=SDA), 地址 0x40, CH0-8 → 舵机 9-17
- V+ 接 UBEC 6V 输出
- OE 接 GND (始终使能)
- 注意: V+ 和 OE 必须接线，否则舵机不转
