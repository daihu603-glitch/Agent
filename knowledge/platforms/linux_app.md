# Linux 应用产品开发

## 架构与构建
- 明确发行版、libc、内核、架构（ARM/x86/aarch64）、动态/静态链接和 sysroot。
- CMake toolchain file 固定编译器、sysroot、查找根路径；发布构建保存依赖版本和许可证。
- 服务拆分为采集、协议、业务、存储、通信和监控，线程模型、队列上限、背压与关闭顺序明确。

## 可靠性
- 所有外部输入做长度/格式/范围校验；网络协议处理半包、粘包、超时、重连和重复消息。
- 文件写入采用临时文件 + fsync + 原子替换（按数据可靠性要求），考虑掉电和磁盘满。
- systemd 服务配置 Restart、Watchdog、资源限制、最小权限、只读文件系统和日志轮转。
- 退出时停止接收新任务，等待在途操作，按依赖逆序释放线程/句柄/内存。
- 长稳记录 RSS/VSZ、FD、线程数、CPU、队列深度、时延 P50/P95/P99、丢包和重启次数。

## 调试
- 保留未 strip 的 ELF 与符号文件，core dump 配合 gdb；发布包可 strip，但符号归档必须对应。
- ASan/UBSan/TSan 在测试环境运行，valgrind 按平台可用性使用。
- 日志带启动 ID、版本、时间同步状态、错误上下文；避免高频日志写满存储。

## 交付
可执行文件、systemd unit、默认配置、依赖/许可证、数据库或配置迁移脚本、安装/升级/回滚说明、监控指标和验收证据。客户环境先备份再部署，智能体不自动清数据。
