# AI 智能体应用设计、评测与交付

## 信任边界与模型接入
- APP/浏览器是不可信客户端，模型提供商长期密钥只存后端环境变量或秘密管理服务；客户端使用自身认证、短期会话和配额。
- 模型端点使用域名白名单、TLS、超时和有限重试；记录模型、提示词、工具 schema 和知识库版本，保证评测与发布可追踪。
- 模型输出是不可信建议，不是授权。任何写操作、部署、支付、设备控制或高风险动作都由服务端重新鉴权、参数校验并在必要时人工确认。

## 工具与工作流
- 每个工具声明 name、read/write/control/critical 风险、资源 scopes、参数 schema、超时、幂等和 confirmation_required；默认拒绝未声明工具。
- 工具白名单必须在执行层强制实施，不能只从提示词或 UI 隐藏。验证用户、会话、设备/租户和操作范围，防止跨用户调用。
- 设备控制链路为：模型候选命令 → schema/业务约束 → 用户确认 → 设备命令 → 固件独立限位 → 状态回传。模型不可用时保留安全的本地手动路径。
- 写操作使用命令 ID 和幂等键，超时后先查询状态再决定重试，避免重复开门、重复运动或重复升级。

## 记忆、RAG 与提示注入
- 网页、文档、工具结果和用户附件均按不可信数据处理，与系统指令隔离；不得因检索文本要求而扩大工具权限或泄露秘密。
- RAG 在检索前和返回前执行租户/用户 ACL，记录来源和版本；测试跨租户、被投毒文档、间接提示注入和过期知识。
- 记忆有用途、用户授权、保留天数、删除和导出机制；敏感字段最小化，禁止把密码、API Key 或无必要隐私写入长期记忆。
- 日志默认脱敏 authorization/api_key/token/password，控制 prompt/response 全文的采集范围；监控数据也受访问和保留策略约束。

## 评测与运行
- 评测集覆盖正常任务、边界、工具选择、无效参数、越权、提示注入、提供商超时和回归；保存逐条响应、实际工具调用、失败原因、Token 和时延。
- run_agent_eval 使用执行层安全白名单，只允许 calculator/read_file/list_files/query_knowledge，禁止硬件、SSH、烧录和部署工具。
- 通过率按全部case计算，API 中止和 not_run 不能从分母剔除；质量之外同时记录 P50/P95 时延、成本和错误率。
- 静态密钥/危险代码扫描只是检查之一，还需认证授权、SSRF、注入、CORS、TLS、限流、依赖和运行时安全测试。

## 交付
后端源码与部署清单、模型/提示词/工具版本、权限矩阵、评测集及原始报告、数据保留删除说明、监控告警、降级回滚和人工运营手册。不得交付 .env、密钥、客户会话或向量库隐私数据。
