# DHT22 (AM2302) 温湿度传感器

## 参数
- 温度: -40~80°C, 精度 ±0.5°C
- 湿度: 0-100%RH, 精度 ±2%RH
- 供电: 3.3V ~ 5.5V
- 采样周期: ≥2s (不能快于 0.5Hz)
- 接口: 单总线 (1-Wire 类似协议)

## 接线
- VCC → 3.3V
- DATA → GPIO (需 4.7kΩ 上拉到 VCC)
- GND → GND
- 当前项目: DATA 接 PC15

## 通信时序
1. MCU 拉低 DATA ≥1ms (起始信号)
2. MCU 释放总线，切为输入
3. DHT22 响应: 拉低 80μs → 拉高 80μs
4. 传输 40bit 数据 (湿度16bit + 温度16bit + 校验8bit)
5. 每 bit: 低电平 50μs + 高电平 (26-28μs=0, 70μs=1)

## 数据格式
- Byte0: 湿度整数
- Byte1: 湿度小数
- Byte2: 温度整数
- Byte3: 温度小数 (bit7=1 表示负温度)
- Byte4: 校验 = (Byte0+Byte1+Byte2+Byte3) & 0xFF
- 湿度 = (Byte0×256+Byte1) / 10
- 温度 = ((Byte2&0x7F)×256+Byte3) / 10, 若 Byte2 bit7=1 则取负

## HAL 实现要点
- 需要微秒级延时 (DWT 或 TIM)
- 读取期间关闭中断 (临界区 ~4ms)
- GPIO 模式切换: 输出推挽 → 输入浮空
- PC15 注意: 最大 2mA，但 DHT22 信号电流极小，可用
